# GEN AI Learning Journey

This repository documents my journey of learning Generative AI, LLMs, and LangChain.

## Topics Covered

- Language models and chat models
- OpenAI, Google Gemini, and Hugging Face integrations
- Text and document embeddings
- Query embeddings
- Semantic similarity with cosine similarity
- API key management with `.env`

## Project Areas

- `LANG_CHAIN/Language_Models`: Basic language model usage
- `LANG_CHAIN/Chat_Models`: Chat models from different providers
- `LANG_CHAIN/Embeded_Models`: Embeddings and document similarity

## Setup

Activate the virtual environment and install the dependencies:

```powershell
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Add the required API keys to a local `.env` file before running provider examples.
